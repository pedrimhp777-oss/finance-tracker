# Finance Tracker API 💰

API RESTful para gerenciamento de finanças pessoais desenvolvida com FastAPI, SQLAlchemy e Pydantic.

## 🚀 Tecnologias Utilizadas
- **Python 3.12+** & **FastAPI**
- **SQLAlchemy** & **SQLite**
- **JWT (JSON Web Tokens)** & **Bcrypt** para Autenticação Segura
- **Scalar UI** para Documentação Interativa
- **Pytest** para Testes Automatizados
